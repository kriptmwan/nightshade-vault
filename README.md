Nightshade Vault — a top-down stealth game. You are a quiet thief in three guarded halls: sneak past patrols with real vision cones and line of sight, hide in bushes and dark floor, throw pebbles to pull guards away, take every emerald, then reach the green exit unseen. Guards get suspicious before they raise the alarm, so a near miss is a warning, not a death sentence. Pure static files under `game/` — no build step, no network requests, keyboard and mouse play, all sounds synthesised in the browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. `WASD` / arrows move, `Shift` sneaks, click throws a pebble, `M` mutes, `R` restarts, `P` pauses, `Enter` starts and advances.
